## Which file do I edit?

**`firmware/apps/blink-pc7/src/app.c`.**

It is the SDK's "idle" application with the blink added. The build copies it over `apps/spp_and_le/examples/idle/app_idle.c` in a fresh SDK clone (the `copy` line in `app.conf`). Do not edit anything under `fw-AC63_BT_SDK/`; it is only a reference, and the build never reads it.

What is in `app.c`:

- `BLINK_PIN` (`IO_PORTC_07`) and `BLINK_PERIOD_MS` (500) at the top.
- `idle_timer_handle_test()`: the timer callback; toggles the pin with `gpio_write`.
- `idle_app_start()`: sets the pin up (`gpio_set_die`, pulls off, `gpio_direction_output`) and starts a `sys_timer` with the callback.
- The rest is the unchanged SDK application skeleton (`REGISTER_APPLICATION`, event handler, state machine).

Settings that are not code (which app runs, Bluetooth off, 512 KiB flash) are `set` lines in `firmware/apps/blink-pc7/app.conf`.

## Apps

Each directory under `firmware/apps/` is one firmware; the file to edit is always its `src/app.c`.

| App | What it does | Status |
|---|---|---|
| `blink-pc7` | Toggles PC7 every 500 ms. | Flashed, runs on the printer. |
| `hello-cdc` | Enumerates as a USB CDC serial port (`/dev/ttyACM0`) and sends `hello world 1`, `hello world 2`, ... once a second. Also blinks PC7 as a heartbeat (slow = port open, fast = waiting for the PC). | Compiles and links; built locally in the sandbox (`build/hello-cdc-local/`, not via `remote-build.sh`). Image made with `tools/patch_app.py`: `work/image/hello-cdc.slice.bin` (flash with `write 0x3000`). **Not flashed yet.** |

`hello-cdc` uses the chip's USB DP/DM pins, so there is no GPIO pin to choose. `app.conf` turns on the SDK's PC module (`TCFG_PC_ENABLE`) and sets the USB class to `CDC_CLASS`; `app.c` calls the SDK's `usb_start()` and then `cdc_write_data()`. The SDK refuses writes until the PC has opened the port, so the counter only advances once a terminal is attached (e.g. `picocom /dev/ttyACM0`).

## Adding another app

1. Copy `firmware/apps/blink-pc7/` to `firmware/apps/<name>/`.
2. Edit `src/` and `app.conf` (`target`, `set`, `copy` lines; the file header explains each).
3. `scripts/remote-build.sh <name>`.

`set` lines fail the build if the `#define` is missing or appears more than once, so an SDK change cannot silently change what is built. New C files need to be added to the SDK's board Makefile, which is a large explicit list; the practical route today is to replace an existing SDK file, as blink-pc7 does. A cleaner way to add files is not built yet (see [journal.md](journal.md), "Not done").

## Generated, safe to delete

- `build/` is regenerated by `scripts/remote-build.sh`.

## Scratch and leftovers (nothing here is needed by the pipeline)

These were left from the exploration phase. They were **not** cleaned up.

| Path | What it is |
|---|---|
| `work/AC63_BT_SDK-blink/` | ~530 MB copy of the SDK used for the first build. Superseded by `firmware/` + `scripts/`. |
| `work/image/` | **Keep.** The exact images written to the printer (see [flashing.md](flashing.md)): `printer-blink.slice.bin`, `printer-blink.bin`, `original.slice.bin`, plus readback files if any. |
| `work/cmp/`, `work/keyed/`, `work/app-*.bin` | Throwaway comparison files, a generated key file, and test builds. |
| `artifacts/blink-pc7-512k/` | Output of the first build. `app.bin` here is the one that was flashed. `jl_isd.bin`/`jl_isd.fw` are in the SDK's own layout and are **not** usable on this chip (wrong layout, wrong chip key). |
| `AC695N_Soundbox_SDK/` | 254 MB. Evaluated and rejected: its payload is larger than the whole flash. Kept only as reference for the original firmware's family. |
| `fw-AC63_BT_SDK/` | 800 MB, of which ~85% is other chips (`cpu/bd19`, `bd29`, `br25`, `br30`, `br34`), unused example apps and vendor docs. Only `cpu/br23`, `include_lib`, `apps/common` and `apps/spp_and_le` matter for this chip. Because it is a git checkout, trimming it with `git sparse-checkout` is reversible. |

## On the build host (karna)

| Path | What it is |
|---|---|
| `/opt/jieli/` | JieLi toolchain (clang for `pi32v2`) |
| `/opt/utils/remove_tailing_zeros` | the one post-build helper still used (the other tools in that package are not) |

| `~/thermal-printer/FM-1-transporter/jl-uboot-tool/` | copy of the flashing tool |
| `~/thermal-printer/work/` | scratch, including `AC63_BT_SDK-blink` (~570 MB) and `image/` with the flashed images |
